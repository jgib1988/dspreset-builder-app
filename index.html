Decent Sampler Preset Builder

How to use

This page builds a Decent Sampler preset (.dspreset) from a folder of WAV samples. Your audio stays on your computer: it is read in your browser and never uploaded. Only the preset file is saved.

Name your samples Name_Note_vN_rrN.wav, e.g. Piano_C3_v1_rr1.wav. The note is a name (C3, F#2, Bb1) or a MIDI number (0–127), with middle C = C3 (MIDI 60). v is the velocity layer and rr the round-robin, each counted from 1. Files that don't match are flagged and left out.

  1. Click Pick sample folder and choose the folder your samples are in.
  2. Check the file table and the mapping grid.
  3. Optionally set the envelope, effects, modulators and plugin controls.
  4. Click Export .dspreset. It downloads (usually to your Downloads folder).
  5. Move the .dspreset into the same folder as the samples, then open it in Decent Sampler.
  • Presets need Decent Sampler 1.34.0 or later. Some effects, such as the filter types, behave differently in older versions.
  • Chrome or Edge give the best folder picker. Other browsers work too, but the folder dialog looks different.
  • Save project keeps your work as a .json file. To carry on later, load it, then pick the sample folder again.

You can also drop a .dsproject.json file anywhere on this page to load it.

Mapping

Drag a zone to move it, or drag its edges to resize it. Re-picking the folder keeps the mapping and loops of files that are still there.

Release samples

Tick the sample names that should play when a key is released (e.g. a piano's damper sound). They get their own mapping: pick "Key up" above the grid to see and edit it.

Key switches

Give sample names an articulation, then pick a key for each articulation: pressing that key switches to it (the key itself doesn't play). Each articulation gets its own mapping: pick it above the grid.

Choke groups

Samples in the same choke group cut each other off, e.g. a closed hi-hat stops an open one. A sound also cuts off its own previous hit.
